Park in a driveway near the game

ezPark lets drivers reserve a neighbor’s driveway near the stadium or arena, and lets hosts list their driveway in about a minute and get paid.

Two sides of the same driveway

The whole marketplace loop works end to end, from listing a driveway to parking in it.

Drivers

  1. Search a stadium, arena, or event
  2. Compare driveways on a map by walking time and total price
  3. See the approximate area, then reserve and pay
  4. Get the exact address, instructions, and a photo of the spot

Hosts

  1. Enter an address and pick nearby venues and events
  2. Set how many cars fit, a flat or hourly price, and open hours
  3. Set up payouts once
  4. Go live, with a 10% platform fee per booking

Details I cared about

The parts that make a two sided marketplace trustworthy.

Privacy before payment

Search and listing pages never receive a host’s exact address, coordinates, or photo. Only a fuzzed point and a “Near X St” label.

No double booking

Capacity is checked inside the booking transaction, so a driveway can never take more cars than it fits.

Driver protection

If a spot is blocked, drivers get an instant full refund and nearby options for the same event. Free cancellation up to 24 hours before.

Host accountability

Host cancellations refund the driver, and three in 90 days pauses that host’s listings.

Tested end to end

A browser test runs the full core loop on desktop and phone sizes, from listing to booking to parking.

Run it locally

ezPark is an MVP with test mode payments, so no real money moves. It needs Node 20 or newer.

Clone the repo, add an AUTH_SECRET to .env, then open http://localhost:3000.

git clone -b mvp https://github.com/muppt11/ezPark.git
cd ezPark
npm install
cp .env.example .env
npx prisma migrate dev
npm run db:seed
npm run dev
